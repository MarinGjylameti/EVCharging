# Project instructions

- Apply routine code edits inside this project without asking for confirmation.
- Never create Git commits or push changes. The user handles commit and push.
  When the changes and checks are ready, tell the user they can commit and push.
- Ask before commands that access the external network, changes or commands
  outside this project, or installation of global/system dependencies.
- Use the installed CSharpier to format handwritten C# code.
- Keep OCPP transport, persistence and protocol parsing in Infrastructure;
  keep application contracts independent of the OCPP protocol.
